# AIVEST ブランドカラー定義書

## 1. 色彩心理学とAI/テック企業のカラー戦略

### 色が持つ心理的効果

| 色 | 心理効果 | ビジネスでの意味 |
|---|---|---|
| **ディープネイビー** | 信頼、知性、安定、専門性 | BtoB企業の基盤色。日本市場で最も「プロフェッショナル」と認識される |
| **グリーン（黄緑〜緑）** | 成長、進化、安全、持続可能性 | AI企業で2番目に多い色。ChatGPTの影響で「AI＝緑」の認知も形成中 |
| **オレンジ** | エネルギー、創造性、温かみ、親しみ | 赤の情熱＋黄色の楽観。行動喚起に強いが、使いすぎると安価な印象になるリスク |
| **イエロー** | 楽観、知性、明るさ、注意喚起 | アクセント使いで効果的。大面積使用は疲労感を与える |
| **パープル** | AI・革新・創造性・先進性 | AI製品で最も多く使われる色。紫→青のグラデーションがトレンド |

### AI/テック企業のカラートレンド（2025-2026）

1. **パープルがAI業界で最優勢** — AI機能を持つ製品の大半がパープルを採用
2. **グリーンが2番手** — ChatGPTの影響で「AI＝グリーン」の認知が形成
3. **グラデーション多用** — 単色よりも紫→青、緑→青のグラデーションが主流
4. **ダークモード対応** — ディープネイビーやダークグレーをベースにネオンアクセント
5. **温かみのあるニュートラル** — AI時代に「人間味」を出すため、冷たい灰色より暖色系ニュートラルが増加

### 日本BtoB市場の色彩戦略

- **青系が圧倒的に信頼される** — freee、Sansan、マネーフォワードなど日本BtoB SaaSの大半が青基調
- **青×黒＝知性・重厚感** — IBM、Intel型のプロフェッショナル表現
- **差別化の余地** — 青一色の市場で、緑〜オレンジのグラデーションは強い差別化要素

## 3. AIVESTカラーパレット提案

### 設計思想

AIVESTのロゴ（黄緑→黄→オレンジのグラデーション）を活かしつつ、BtoB市場で必要な「信頼感・専門性」を補完するカラーシステム。

**コンセプト: 「Growth Intelligence（成長する知性）」**

- ロゴのグラデーション = 成長・上昇・エネルギー（暖色系の人間味）
- ネイビー = 知性・信頼・専門性（冷色系の信頼感）
- この対比が「AIの力で人間の成長を支援する」というAIVESTのミッションを表現

---

### Primary Color（プライマリ）

#### AIVEST Navy — アイベストネイビー
```
HEX: #1B2A4A
RGB: (27, 42, 74)
```
- **命名**: 「AIVEST Navy / アイベストネイビー」
- **意味**: 信頼、知性、専門性、安定
- **用途**: サイトのヘッダー、フッター、主要見出し、ボタンのベース色
- **使用場面**: ナビゲーションバー、CTAボタン、セクション背景、名刺・提案書の基調色
- **選定根拠**:
  - 日本BtoB市場で「信頼」を最も伝える色
  - ロゴの暖色グラデーションとの補色関係で視覚的バランスが取れる
  - 純粋な黒より温かみがあり、普通の青より深みと重厚感がある
  - WCAG AA基準で白文字とのコントラスト比 12.6:1（AAA合格）

---

### Secondary Color（セカンダリ）

#### AIVEST Lime — アイベストライム
```
HEX: #7CB518
RGB: (124, 181, 24)
```
- **命名**: 「AIVEST Lime / アイベストライム」
- **意味**: 成長、進化、AI技術の可能性、上昇
- **用途**: サブ見出し、アイコン、カード装飾、進捗表示
- **使用場面**: サービス紹介セクション、成長を示すグラフ、ステータスバー、タグ
- **選定根拠**:
  - ロゴの左端（成長の起点）の色を正式カラーとして定義
  - ChatGPTの影響で「緑＝AI」の認知が形成されつつあり、AI企業として自然
  - ネイビーとの組み合わせで「知性×成長」のメッセージ
  - 黄緑は日本市場で「新しさ」「フレッシュさ」を想起させる

---

### Accent Color（アクセント）

#### AIVEST Amber — アイベストアンバー
```
HEX: #E8920D
RGB: (232, 146, 13)
```
- **命名**: 「AIVEST Amber / アイベストアンバー」
- **意味**: エネルギー、温かみ、行動喚起、価値
- **用途**: CTA強調、重要な数値、バッジ、プライシングのハイライト
- **使用場面**: 「お問い合わせ」ボタン、キャンペーンバナー、料金表のおすすめプラン、通知
- **選定根拠**:
  - ロゴの右端（到達点・成果）の色を洗練させたもの
  - 純粋なオレンジより「安価」な印象を避け、ゴールド寄りにシフト
  - ネイビー背景上で高い視認性（コントラスト比 5.8:1 — AA合格）
  - 「成果」「達成」「投資価値」を連想させ、経営支援サービスに最適

---

### Gradient — ブランドグラデーション

#### AIVEST Gradient — アイベストグラデーション
```
CSS: linear-gradient(135deg, #7CB518 0%, #E8C516 50%, #E8920D 100%)
方向: 左下→右上（135deg）= 上昇・成長の方向
```
- **構成色**:
  - 起点: `#7CB518`（ライム — 成長の始まり）
  - 中間: `#E8C516`（ゴールドイエロー — 加速・転換点）
  - 終点: `#E8920D`（アンバー — 成果・達成）
- **用途**: ロゴ周辺、ヒーローセクションのアクセント、区切り線、ボタンホバー
- **選定根拠**: ロゴのグラデーションを忠実に再現しつつ、Web上で映えるよう調整

### Neutral Colors（ニュートラル）

| カラー名 | HEX | RGB | 用途 |
|---|---|---|---|
| **Dark（ダーク）** | `#1A1A2E` | (26, 26, 46) | メインテキスト、ダークモード背景 |
| **Charcoal（チャコール）** | `#3D3D5C` | (61, 61, 92) | サブテキスト、セカンダリテキスト |
| **Slate（スレート）** | `#6B7280` | (107, 114, 128) | プレースホルダー、補足テキスト、ボーダー |
| **Silver（シルバー）** | `#D1D5DB` | (209, 213, 219) | ディバイダー、ボーダー、無効状態 |
| **Cloud（クラウド）** | `#F3F4F6` | (243, 244, 246) | セクション背景（交互）、カード背景 |
| **Snow（スノー）** | `#FAFBFC` | (250, 251, 252) | ページ背景 |

- **選定根拠**: わずかにブルー寄りのニュートラルで、プライマリのネイビーとの統一感を確保。純粋なグレーより「冷たすぎない」温度感。

## 4. カラー組み合わせルール

### 60-30-10 ルール

```
60% — ニュートラル（Snow/Cloud）: ページ背景・余白
30% — プライマリ（AIVEST Navy）: ヘッダー、テキスト、セクション背景
10% — アクセント（AIVEST Lime + Amber）: CTA、アイコン、装飾
```

### コントラスト比一覧（WCAG 2.1 準拠）

| 前景色 | 背景色 | コントラスト比 | 判定 |
|---|---|---|---|
| Snow `#FAFBFC` | Navy `#1B2A4A` | **12.6:1** | AAA ✅ |
| Dark `#1A1A2E` | Snow `#FAFBFC` | **15.2:1** | AAA ✅ |
| Navy `#1B2A4A` | Cloud `#F3F4F6` | **11.4:1** | AAA ✅ |
| Snow `#FAFBFC` | Amber `#E8920D` | **2.1:1** | ❌ 文字非推奨 |
| Dark `#1A1A2E` | Amber `#E8920D` | **4.6:1** | AA ✅（通常テキスト） |
| Navy `#1B2A4A` | Lime `#7CB518` | **4.1:1** | AA ✅（大文字のみ） |
| Dark `#1A1A2E` | Lime `#7CB518` | **5.0:1** | AA ✅ |

### 重要な使用ルール

1. **アンバーの上に白文字を置かない** — コントラスト不足。アンバー上はダークテキストを使用
2. **ライムの上にはネイビーまたはダークテキスト** — 白文字は非推奨
3. **ネイビー背景には白または極薄の文字のみ** — AA以上を確保
4. **グラデーションの上にテキストを置く場合は半透明のオーバーレイを併用**

### グラデーションの使用ルール

| 場面 | 方向 | 効果 |
|---|---|---|
| ヒーローセクション | 135deg（左下→右上） | 上昇・成長のストーリー |
| 区切り線・アクセント | 90deg（左→右） | 流れ・進行 |
| ボタンホバー | 90deg（左→右） | 動的な変化 |
| 背景装飾 | 180deg（上→下） | 安定・落ち着き |

### アクセントカラーの使用比率

- **ライム（セカンダリ）**: 全体の15〜20%。セクション装飾、アイコン、タグに使用
- **アンバー（アクセント）**: 全体の5〜10%。CTA、重要ハイライトに限定使用
- **グラデーション**: ロゴ周辺と特別なセクション（ヒーロー、CTA帯）のみ。多用しない

## 5. ロゴカラーとWebサイトの統合戦略

### 現状の課題

- ロゴ: 黄緑→黄→オレンジ（暖色グラデーション）
- 現サイト: 青 `#3b82f6`（Tailwind blue-500）が中心
- **統一感がなく、ロゴが「浮いて」見えるリスク**

### 統合アプローチ

#### A. ネイビーをブリッジカラーにする

```
ロゴ（暖色）←→ ネイビー（中間）←→ サイト全体
```

- 現在の `#3b82f6`（明るい青）→ `#1B2A4A`（ディープネイビー）に変更
- ネイビーは暖色にも寒色にも寄りすぎない「ブリッジ」として機能
- ロゴの暖色グラデーションがネイビー背景上で映える

#### B. サイト全体のカラー配分

```
┌─────────────────────────────────────────────┐
│  ヘッダー: Navy #1B2A4A                      │
│  ロゴ: Gradient（黄緑→黄→オレンジ）           │
├─────────────────────────────────────────────┤
│  ヒーローセクション:                          │
│    背景: Snow #FAFBFC                        │
│    グラデーションアクセント（左右に装飾）       │
│    テキスト: Dark #1A1A2E                    │
│    CTA: Navy背景 + Snow文字                  │
├─────────────────────────────────────────────┤
│  サービス紹介:                                │
│    背景: Cloud #F3F4F6                       │
│    カードボーダー: Lime #7CB518（左線）        │
│    アイコン: Lime + Amber                    │
├─────────────────────────────────────────────┤
│  実績/信頼セクション:                         │
│    背景: Navy #1B2A4A                        │
│    テキスト: Snow #FAFBFC                    │
│    数値: Amber #E8920D                       │
├─────────────────────────────────────────────┤
│  CTA帯:                                     │
│    背景: Gradient（135deg）                   │
│    テキスト: Dark #1A1A2E                    │
│    ボタン: Navy背景 + Snow文字               │
├─────────────────────────────────────────────┤
│  フッター: Dark #1A1A2E                      │
│  テキスト: Silver #D1D5DB                    │
│  アクセント: Lime #7CB518（リンクホバー）      │
└─────────────────────────────────────────────┘
```

#### C. 旧カラーからの移行マッピング

| 旧カラー | 用途 | 新カラー | 理由 |
|---|---|---|---|
| `#3b82f6` (blue-500) | メインUI | `#1B2A4A` Navy | より深く重厚に。ロゴとの補色関係 |
| `#84cc16` (lime-500) | アクセント | `#7CB518` Lime | ほぼ同系色。彩度をやや調整 |
| `#eab308` (yellow-500) | 強調 | `#E8920D` Amber | イエロー→アンバーに寄せてロゴ終点と統一 |

## 6. Tailwind CSS カラー設定

```typescript
// tailwind.config.ts での設定例
const colors = {
  aivest: {
    // Primary
    navy: {
      DEFAULT: '#1B2A4A',
      light: '#2A3F6B',
      dark: '#111D33',
    },
    // Secondary
    lime: {
      DEFAULT: '#7CB518',
      light: '#9BD635',
      dark: '#5E8A12',
    },
    // Accent
    amber: {
      DEFAULT: '#E8920D',
      light: '#F5A623',
      dark: '#C47A0A',
    },
    // Gradient midpoint
    gold: '#E8C516',
  },
  // Neutral
  neutral: {
    dark: '#1A1A2E',
    charcoal: '#3D3D5C',
    slate: '#6B7280',
    silver: '#D1D5DB',
    cloud: '#F3F4F6',
    snow: '#FAFBFC',
  },
  // Semantic
  semantic: {
    success: '#059669',
    warning: '#D97706',
    error: '#DC2626',
    info: '#2563EB',
  },
}
```
