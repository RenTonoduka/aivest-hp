# AIVEST ブランドカラー定義書

## ブランドストーリー

**AIVEST = AI + INVEST（AIに投資する価値を届ける）**

> 深い洞察（Deep Navy）から革新（Indigo）が生まれ、
> 確かな成果（Emerald）として実を結ぶ。

「構想から実装まで一気通貫」— AIVESTの提供価値をカラーで体現するシステム。

## カラー設計の根拠

### なぜ Navy × Indigo か

1. **同じ青族** — グラデーションの中間色が濁らない（Navy→Lime は中間がオリーブ色に濁っていた）
2. **AI業界のトレンド** — パープル/インディゴがAI製品で最も多く使われる色（2025-2026）
3. **日本BtoB市場との適合** — 青系は「信頼・専門性」を最も伝える。Indigo で差別化
4. **ロゴとの対比** — ロゴの暖色（黄緑→オレンジ）がクール系サイト上で際立つ

### 競合との差別化

| 企業 | メインカラー | AIVESTとの違い |
|------|-------------|---------------|
| Anthropic | テラコッタ `#D97757` | 暖色系。AIVESTはクール系で知性を訴求 |
| OpenAI | グリーン `#10A37F` | 単色。AIVESTはグラデーションで進化を表現 |
| PKSHA | レッド `#EF3F35` | 情熱。AIVESTは知性と革新 |
| freee / Sansan | ブルー系 | 標準的な青。AIVESTはIndigoで先進性を加える |

## 使用ルール

### 60-30-10 ルール

```
60% — ニュートラル（Background / Cloud）: 余白・背景
30% — プライマリ（Deep Navy）: テキスト・ヘッダー・セクション
10% — アクセント（Indigo + Emerald）: グラデーション・装飾・ステータス
```

### コントラスト比（WCAG 2.1 準拠）

| 前景色 | 背景色 | コントラスト比 | 判定 |
|--------|--------|---------------|------|
| Background | Navy `#0F172A` | **15.4:1** | AAA |
| Navy `#0F172A` | Background | **15.4:1** | AAA |
| White | Indigo `#4F46E5` | **4.6:1** | AA |
| Navy `#0F172A` | Cloud `#F1F5F9` | **13.8:1** | AAA |
| Charcoal `#475569` | Background | **6.3:1** | AA |

### やってはいけないこと

1. **Indigo の上に薄い文字を置かない** — 白文字のみ許可
2. **Emerald をグラデーションに混ぜない** — スポットカラーとして独立使用
3. **グラデーションを大面積に使わない** — テキスト・アクセント線・装飾に限定
4. **3色以上のグラデーションを作らない** — Navy→Indigo, Indigo→Indigo Light のみ
